# Архитектура

Игра — статический сайт без сборщиков. Каждый модуль подключается
классическим `<script>` в `index.html` и вешает себя на `window`.

## Слои

| Модуль        | Ответственность                                       |
|---------------|-------------------------------------------------------|
| `utils.js`    | формат чисел, цена апгрейдов, длительности            |
| `data.js`     | статические данные: здания, апгрейды                  |
| `state.js`    | живое состояние и расчёты (CPS, сила клика, буст)     |
| `save.js`     | localStorage, экспорт/импорт в base64                 |
| `cookie.js`   | большое печенье, клики, всплывающие +N                |
| `shop.js`     | магазин зданий и улучшений                            |
| `golden.js`   | спавн и эффекты золотых печений                       |
| `achievements.js` | проверка целей, уведомления                      |
| `encyclopedia.js` | открытие печений, фильтры, бонус CPS             |
| `stats.js`    | окно статистики                                       |
| `offline.js`  | кредиты за время отсутствия (лимит 8 ч)               |
| `prestige.js` | перерождение за «души»                                |
| `sounds.js`   | синтез звуков на WebAudio                              |
| `settings.js` | громкость, экспорт/импорт, сброс                      |
| `main.js`     | сборка DOM, игровой цикл 1с, автосохранение 10с        |

## Потоки данных

Состояние хранится в одном объекте и передаётся через лёгкий `store`
(`get()`/`set()`). `set()` сразу пишет сейв — рискованно при частых тиках,
поэтому цикл вызывает `set` раз в секунду, а автосохранение — раз в 10 секунд.

Экономика повторяет классический Cookie Clicker: цена здания =
`base × 1.15^owned`, CPS здания суммируется с множителями апгрейдов,
престиж удваивает, а энциклопедия даёт +0.1% CPS за каждое найденное печенье.
