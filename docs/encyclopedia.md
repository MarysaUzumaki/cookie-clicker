# Печеньевая энциклопедия

Формат данных: JSON Lines, одна строка = одно печенье.

```json
{"id":"1","name":"Классическое масло","rarity":"Обычное","value":40,
 "bonus":0.1,"flavor":"Хрустит как первый снег в пекарне. Крошка."}
```

- `id` — сквозной номер рецепта;
- `name` — уникальное сочетание «прилагательное + существительное»;
- `rarity` — Обычное/Необычное/Редкое/Эпическое/Легендарное/Мифическое;
- `value` — порог totalBaked, при котором печенье открывается;
- `bonus` — прибавка к CPS за эту находку (в %);
- `flavor` — вкусовая история из шаблонов.

Генератор `scripts/generate_cookies.py` детерминирован: один seed,
одинаковый порядок. Данные валидирует `scripts/check_data.py`,
а `scripts/build_data.py` собирает `src/data/cookies.js`.

Скорость открытия честнее всего читать из `value`: чем больше печенья уже
испечено — тем более экзотические рецепты разблокируются.
