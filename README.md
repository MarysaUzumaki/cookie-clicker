# Cookie Clicker (petbot edition)

Классический кликер «печенье» на чистом HTML/CSS/JS — без сборщиков и зависимостей.
Открывается двойным кликом по `index.html`.

## Как играть

- Кликайте по большому печенью в центре — каждая крошка идёт в копилку.
- Покупайте здания и улучшения в магазине справа: они приносят печенье в секунду.
- Ловите золотые печенья — они дают временные множители кликов.
- Открывайте «Печеньевую энциклопедию»: каждое найденное печенье записывается туда.
- Достигайте порогов и сбрасывайте печенье за престиж.
- Прогресс сохраняется автоматически каждые 10 секунд.

## Структура

- `src/` — исходники игры (логика вынесена в отдельные модули).
- `data/cookies.jsonl` — энциклопедия печений (одно печенье = одна строка).
- `scripts/` — генераторы и проверки данных.
- `docs/` — документация архитектуры и баланса.

## Разработка

Одно печенье энциклопедии — один коммит. Это обеспечивает честную и
прослеживаемую историю: `git log --oneline` читается как каталог открытий.
